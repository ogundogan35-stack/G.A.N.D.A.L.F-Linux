# ============================================================
#  GANDALF - Voice command mapping file  (commands.txt)
# ============================================================
#  Open this file in Notepad and ADD / EDIT YOUR OWN voice
#  commands. You do NOT need to rebuild the exe.
#
#  Rule: each line is one mapping.
#     spoken_phrase = command
#
#  "spoken_phrase": what you say in the command (lowercase).
#  "command": the command format Gandalf understands. Use these:
#      open <app>                  -> opens the app        (e.g. open chrome)
#      close <app>                 -> closes the app       (e.g. close chrome)
#      weather in <city>           -> weather report       (e.g. weather in Antalya)
#      send a message to <person> saying <message>  -> sends a message
#      search <question>           -> searches the web
#
#  Lines starting with # are comments. Blank lines are ignored.
#  When you say something, the first mapping whose "spoken_phrase"
#  matches the text is run (checked from top to bottom).
# ============================================================
